Direct Mode

The quickest way to produce a PDF — no template or data file required. Pass content inline via flags. Useful for cover pages, quick notes, or testing style presets.

Basic usage

bash
# Title only
java -jar pdf-creator.jar --title "Q1 Account Summary" --output output/cover.pdf

# Title + inline body text
java -jar pdf-creator.jar \
  --title  "Notice to Customer" \
  --text   "Your account has been updated." \
  --output output/notice.pdf

# Body text from a file, with style preset
java -jar pdf-creator.jar \
  --title     "Annual Report 2026" \
  --text-file content/report.txt \
  --config-id report \
  --output    output/annual-report.pdf

Config presets (--config-id)

Preset IDPageCharacter
defaultA4Helvetica, 50 pt margins, neutral black — all-purpose
reportA4Wider margins (72 pt), navy title colour — formal reports
letterLetterTimes Roman, generous margins — business correspondence
compactA4Courier, tight 30 pt margins — data-dense documents
darkA4Light text on #1E1E1E background — modern/digital look
brandedA4White titles on navy background — brand cover pages

Direct mode flags

FlagRequiredDescription
--title <text>YesDocument title rendered as a large heading on page 1
--text <text>NoInline body text. Use \n for paragraph breaks
--text-file <path>NoRead body text from a plain-text file
--output <path>YesOutput PDF file path
--config-id <id>NoStyle preset name. Default: default
--config-file <path>NoPath to pdf-configs.json. Default: configs/pdf-configs.json
--author <text>NoDocument author metadata
--subject <text>NoDocument subject metadata

Template Mode

Combines a JSON template (structure & layout) with a JSON data file (runtime values). Placeholders in the template — {{customer.name}} — are resolved against the data before rendering. Missing keys produce a warning; rendering does not fail.

Usage

bash
java -jar pdf-creator.jar \
  --template-id bank-statement \
  --data-file   data/statements/statement-001.json \
  --output      output/statement-001.pdf

# Override config preset and add metadata
java -jar pdf-creator.jar \
  --template-id credit-card-summary \
  --data-file   data/cards/card-007.json \
  --config-id   compact \
  --output      output/card-007.pdf \
  --title       "Card Statement March 2026" \
  --author      "First National Bank"

Batch Mode

Generates many personalised PDFs in parallel using a thread pool. Every job uses the same template with a different data file. Signing and PDF/A compliance can be layered on in the same pass.

From a directory of JSON files

bash
java -jar pdf-creator.jar \
  --batch \
  --template-id bank-statement \
  --data-dir    data/statements/ \
  --output-dir  output/statements/ \
  --threads     8

From a CSV file

bash
java -jar pdf-creator.jar \
  --batch \
  --template-id credit-card-summary \
  --csv-file    data/march-accounts.csv \
  --output-dir  output/march/ \
  --threads     4
ℹ
CSV column headers become placeholder keys. Each row generates one PDF. Output filenames are derived from the row index unless the data includes a filename column.

Batch + PDF/A + sign in one pass

bash
java -jar pdf-creator.jar \
  --batch \
  --template-id       bank-statement \
  --data-dir          data/statements/ \
  --output-dir        output/signed/ \
  --threads           4 \
  --pdfa \
  --sign \
  --keystore          bank.p12 \
  --keystore-password secret \
  --reason            "Monthly Account Statement" \
  --tsa-url           http://timestamp.digicert.com
ℹ
Each PDF is generated, PDF/A markers are attached, then it is digitally signed — all in the same pipeline pass. The unsigned intermediate file is never written to disk.

Text Extraction

Extracts text from any existing PDF using PDFBox's PDFTextStripper. Supports page ranges, position-based sorting, whitespace normalisation, per-page output, and password-protected PDFs.

bash
# Extract all text to stdout
java -jar pdf-creator.jar --extract --input report.pdf

# Pages 2–5, write to file
java -jar pdf-creator.jar --extract \
  --input      report.pdf \
  --output     report.txt \
  --start-page 2 --end-page 5

# Strip extra whitespace, suppress metadata header
java -jar pdf-creator.jar --extract \
  --input           report.pdf \
  --strip-whitespace \
  --no-metadata

# Password-protected PDF
java -jar pdf-creator.jar --extract \
  --input    secured.pdf \
  --password userpass
FlagDefaultDescription
--extract—Activates text extraction mode
--input <path>—Source PDF (required)
--output <path>stdoutDestination text file
--start-page <n>1First page, 1-based
--end-page <n>lastLast page. -1 = last page
--sort-by-positiontrueSort text fragments by Y/X coordinates before output
--strip-whitespacefalseCollapse multiple spaces and trim each line
--no-metadatafalseSuppress the document information dictionary in output
--password <pwd>—Password for encrypted PDFs (tried as both user and owner)

Image Extraction

Iterates all pages using PDResources.getXObjectNames() and saves every PDImageXObject to the output directory. Use minimum dimension filters to skip tiny decorative elements like icons or rule lines.

bash
# Extract all embedded images
java -jar pdf-creator.jar --extract --extract-images \
  --input      report.pdf \
  --output-dir images/

# Only images ≥ 100×100 px, saved as JPEG
java -jar pdf-creator.jar --extract --extract-images \
  --input        report.pdf \
  --output-dir   images/ \
  --image-format jpeg \
  --min-width    100 \
  --min-height   100

# Extract images from pages 3–7 only
java -jar pdf-creator.jar --extract --extract-images \
  --input      report.pdf \
  --output-dir images/ \
  --start-page 3 --end-page 7
FlagDefaultDescription
--extract-images—Activates image extraction (combine with --extract)
--output-dir <path>—Directory for extracted images (required)
--image-format <fmt>pngpng or jpeg
--min-width <px>0Skip images narrower than this pixel count
--min-height <px>0Skip images shorter than this pixel count
--start-page / --end-pageallLimit extraction to a page range
--password <pwd>—Password for encrypted PDFs

Merge

Combines two or more PDFs into a single output using PDFBox's appendDocument() API. All page content, bookmarks, and metadata are preserved from each source. Input order determines page order in the output.

bash
java -jar pdf-creator.jar --merge \
  --input  cover.pdf report.pdf appendix.pdf \
  --output combined.pdf
FlagRequiredDescription
--mergeYesActivates merge mode
--input <p1> <p2> …YesTwo or more source PDFs in merge order
--output <path>YesOutput PDF file path
ℹ
When at least one input is PDF/A, the merged output automatically inherits PDF/A compliance markers and the sRGB output intent.

Split

Divides one PDF into multiple output files. Three strategies are available via --split-mode. Each output part inherits PDF/A markers from the source if present.

bash
# every-n  — split into chunks of 5 pages
java -jar pdf-creator.jar --split \
  --input          big-batch.pdf \
  --output-dir     parts/ \
  --split-mode     every-n \
  --pages-per-part 5

# into-n  — divide into exactly 3 equal parts
java -jar pdf-creator.jar --split \
  --input      report.pdf \
  --output-dir parts/ \
  --split-mode into-n \
  --num-parts  3

# page-range  — extract pages 3–7
java -jar pdf-creator.jar --split \
  --input      report.pdf \
  --output-dir parts/ \
  --start-page 3 --end-page 7
--split-modeDescriptionRequired extra flag
every-nDivide into chunks of N pages. Last chunk may have fewer.--pages-per-part <n>
into-nDivide into exactly N approximately equal parts.--num-parts <n>
(range)Extract a specific page range using start/end page flags.--start-page + --end-page

Printing

Sends a PDF to any printer accessible to the JVM via the Java Printing API (javax.print). Supports silent printing, duplex modes, page range, copy count, and three scaling modes.

bash
# List all available printers
java -jar pdf-creator.jar --list-printers

# Print silently to the system default printer
java -jar pdf-creator.jar --print --input statement.pdf

# Named printer, pages 1–3, duplex long-edge, 2 copies
java -jar pdf-creator.jar --print \
  --input      statement.pdf \
  --printer    "Finance-HP-4015" \
  --start-page 1 --end-page 3 \
  --sides      duplex-long \
  --copies     2 \
  --silent
FlagDefaultDescription
--print—Activates print mode
--list-printers—Print names of all available printers and exit
--input <path>—PDF file to print (required)
--printer <name>system defaultPrinter name from --list-printers output
--start-page <n>1First page to print, 1-based
--end-page <n>lastLast page to print
--copies <n>1Number of copies
--sides <mode>simplexsimplex | duplex-long | duplex-short
--scaling <mode>fitfit | shrink | actual
--silentfalsePrint without showing a dialog box
--password <pwd>—Password for encrypted PDFs

Rasterization

Renders PDF pages to PNG or JPEG image files using PDFBox's PDFRenderer.renderImageWithDPI(). Output files are named <prefix>-001.png, <prefix>-002.png, etc. — zero-padded to at least 3 digits, auto-expanding for documents over 999 pages.

Usage

bash
# All pages to PNG at 150 DPI (default)
java -jar pdf-creator.jar --rasterize \
  --input      statement.pdf \
  --output-dir statement-pages/

# Print-quality PNG at 300 DPI
java -jar pdf-creator.jar --rasterize \
  --input      statement.pdf \
  --output-dir pages/ \
  --dpi        300

# Pages 1–3 as JPEG at 90% quality
java -jar pdf-creator.jar --rasterize \
  --input        statement.pdf \
  --output-dir   previews/ \
  --format       jpeg \
  --dpi          200 \
  --jpeg-quality 0.90 \
  --start-page   1 --end-page 3

# First-page thumbnail with custom filename prefix
java -jar pdf-creator.jar --rasterize \
  --input       statement.pdf \
  --output-dir  thumbnails/ \
  --dpi         72 \
  --start-page  1 --end-page 1 \
  --file-prefix thumb

DPI guide

DPIUse Case
72Screen thumbnails and small previews — smallest files
150Default — good for on-screen reading and email attachments
300Print quality — recommended for customer-facing document previews
600Archival or OCR pre-processing

Rasterize flags

FlagDefaultDescription
--rasterize—Activates rasterization mode
--input <path>—Source PDF (required)
--output-dir <path>—Directory for output images; created if absent (required)
--format <fmt>pngpng or jpeg
--dpi <n>150Rendering resolution in dots per inch
--jpeg-quality <n>0.85JPEG quality 0.0–1.0. Ignored for PNG
--start-page <n>1First page to render, 1-based
--end-page <n>lastLast page to render

Quick Reference — Part 1

bash — generation
# Direct: simplest possible PDF
java -jar pdf-creator.jar --title "My Document" --output out.pdf

# Template + data
java -jar pdf-creator.jar --template-id <id> --data-file <json> --output <pdf>

# Batch from directory, 8 threads
java -jar pdf-creator.jar --batch --template-id <id> --data-dir <dir> --output-dir <out> --threads 8

# Batch from CSV
java -jar pdf-creator.jar --batch --template-id <id> --csv-file <csv> --output-dir <out>
bash — reading & manipulation
# Extract text (all pages)
java -jar pdf-creator.jar --extract --input <pdf>

# Extract images with size filter
java -jar pdf-creator.jar --extract --extract-images --input <pdf> --output-dir <dir> --min-width 100

# Merge 3 PDFs
java -jar pdf-creator.jar --merge --input a.pdf b.pdf c.pdf --output combined.pdf

# Split every 5 pages
java -jar pdf-creator.jar --split --input <pdf> --output-dir <dir> --split-mode every-n --pages-per-part 5

# List printers, then print silently
java -jar pdf-creator.jar --list-printers
java -jar pdf-creator.jar --print --input <pdf> --printer <name> --silent

# Rasterize all pages to PNG at 300 DPI
java -jar pdf-creator.jar --rasterize --input <pdf> --output-dir <dir> --dpi 300
